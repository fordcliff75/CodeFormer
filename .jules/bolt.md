## 2024-05-23 - [Optimization: Avoid Global Sync & PCIe bottlenecks]
**Learning:** `tensor2img_fast` was initially failing for single-channel 3D tensors because of an unconditional `.squeeze(0)`, and was truncating rather than `.round()`ing pixel values leading to image degradation. We also discovered that calling `torch.cuda.empty_cache()` inside hot loops severely throttles performance because it forces a global GPU sync, overriding PyTorch's efficient caching allocator. Performing rounding and data type casting on the GPU before moving to CPU in `tensor2img_fast` is significantly faster as it drops the memory bandwidth over PCIe by ~4x compared to transferring 32-bit floats.
**Action:** Always conditionally squeeze tensors depending on dimensions (`dim() == 4`), use `.round()` before type casting, move scaling/rounding logic to the GPU before `cpu()`, and aggressively remove `empty_cache()` from inside loops to rely on PyTorch memory allocator.
