## 2024-05-14 - Python Math vs Numpy for simple distances
**Learning:** For minimum distance calculations in list loops, instantiating `np.array` objects and computing `np.linalg.norm` is remarkably slow compared to computing standard squared Euclidean distance via pure Python in a list comprehension. I observed an ~8x performance improvement (1.57s vs 0.18s) doing this in `get_center_face`. It also avoids unnecessary `np.array` allocations for single scalar results where monotonic relative distances are sufficient.
**Action:** When finding minimum/maximum points in Python object arrays/lists, prefer pure-Python `dx**2 + dy**2` over `np.linalg.norm` or `math.dist` if working with very small lists of points in critical loops. Avoid unnecessary array allocations inside loops if the standard python datatypes are adequate.
