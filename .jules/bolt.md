## 2024-05-24 - Optimizing Distance Calculations and Loop Iterations
**Learning:** For finding the minimum distance (e.g., nearest center), calculating a pure-Python squared Euclidean distance (`dx**2 + dy**2`) inside a list comprehension is significantly faster (~12x) than instantiating numpy arrays and calling `np.linalg.norm()` per iteration. However, when replacing manual min/max bounding checks inside loops, readability must not be sacrificed; using python's built-in `max()` and `min()` inside the loop is readable, and far preferred over long, unreadable inline ternary operators.
**Action:** When calculating relative distances for comparison (not exact magnitude), always use squared distance. When refactoring manual coordinate loops, use built-in `min`/`max` rather than inline ternary logic, even if it's slightly faster, to strictly adhere to the readability rule.
