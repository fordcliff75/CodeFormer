## 2024-03-21 - Optimize object-to-prior matching and distance calculations in Python
**Learning:** For finding the minimum distance, pure-Python squared Euclidean distance (dx**2 + dy**2) in a list comprehension is significantly faster (~10-12x) than instantiating NumPy arrays and using np.linalg.norm() inside loops. Also, refactoring manual area-checking loops to use `max(list, key=lambda x: ...)` with built-in `min()` and `max()` bounds checking reduces complexity to $O(n)$ and eliminates intermediate list allocations while maintaining readability.
**Action:** Replace `np.linalg.norm` in tight loops with pure Python math. Avoid inline ternary operators for bounds checking; use standard `min()`/`max()` instead. Use `max(enumerate(items), key=...)` to find both max item and its index in one pass.
