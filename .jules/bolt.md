## 2026-04-06 - [Optimize tensor2img CPU overhead in Inference]
**Learning:** Migrating inference pipelines to use a function that performs PyTorch operations (clamping, scaling, rounding) on the GPU rather than strictly dropping to the CPU via NumPy arrays reduces PCIe bus overhead by nearly 4x, maintaining fast execution. When replacing these utilities across an entire codebase, it's crucial to inspect the tensor shapes properly to allow simple drop-in replacement logic (e.g. conditionally executing `.squeeze(0)` depending on if the shape is `(B, C, H, W)` or already `(C, H, W)` to prevent removing valid channels when `C=1`).
**Action:** When working on performance optimizations in PyTorch pipelines involving GPU-to-CPU transfers, push as much computation (math, type-casting) to the GPU side *before* executing `.cpu().numpy()` and handle shape checking edge cases comprehensively so the drop-in replacement is fully compatible across all dependent scripts.
